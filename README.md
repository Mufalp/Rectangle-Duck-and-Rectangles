# Rectangle-Duck-and-Rectangles

A simple training and racing game where you level up your duck to beat goal times.

## Why I Built This
This project was developed using **C++** and **Raylib**. My main motivation was to experience game development **without a high-level game engine** (like Unity or Unreal). I wanted to understand the "under the hood" logic—handling game loops, physics, and UI mechanics purely through code.

---

## Installation & Running

### Linux & macOS
If you already have **Raylib** installed:
1. Open your terminal in the project folder.
2. Run: `make run`

If you don't have the dependencies, use these scripts to automate the setup:
* **Linux:** `chmod +x setup_linux.sh && ./setup_linux.sh`
* **macOS:** `chmod +x setup_mac.sh && ./setup_mac.sh`

### Windows
If you have **MinGW** and **Raylib** configured in your PATH:
1. Open your terminal (CMD or PowerShell).
2. Run: `make run`

*Note: Building on Windows requires a properly configured environment. If you run into issues, check the pre-built version below.*
